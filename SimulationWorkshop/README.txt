Simulation workshop

The first target is the original OGC authors' cloth, knot, yarn, garment, robot, sphere and volumetric-mat scenarios listed in author_cases.json. These are an inventory, not runnable simulations yet. OGC/material implementations and the workshop UI are separate work from the playable world environments. Do not replace these scenarios with hair, fur, dirt, sand or water-material demonstrations.

The paper benchmark reference is https://graphics.cs.utah.edu/research/projects/ogc/Offset_Geometric_Contact-SIGGRAPH2025.pdf
The authors' project is https://ankachan.github.io/Projects/OGC/
The public Gaia revision examined (c229692) exposes older VBD scenes, not a complete matching OGC benchmark pack. The linked Newton code exposes current cloth_twist and cloth_franka examples. Distinguish current Newton examples from the paper's exact meshes and settings.

No simulation or performance result is claimed by this inventory.
