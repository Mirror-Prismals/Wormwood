# Wormwood source backup

This private repository backs up the Wormwood engine and audio workstation
source as of November 13, 2026. It includes source code, shaders, build scripts,
configuration, documentation, and vendored source dependencies.

Artwork, generated asset payloads, fonts, imported personal audio, saved sessions,
and build output are excluded. They remain on the original machine. This is a
source-only backup; a fresh clone needs the excluded assets before the complete
application can be built, packaged, or run. It does not use Git LFS.

Martin, Prismals, and the preserved Salamander137 project are separate and are
not included here.
