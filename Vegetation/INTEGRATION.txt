QueryGeometry input: position world metres [f64;3], time seconds, max_distance
1..6000 metres, max_triangles <=32768 (default16384). Output: camera-relative
vertices with 16-float stride, indices, instance/site ranges, origin and revision.
Layout: xyz position, xyz normal, uv, rgb color, material, transmission,
roughness, occlusion, bark ridge scale. GL attributes locations0..5 have sizes
3,3,2,3,4,1 and byte offsets0,12,24,32,44,60, stride64. Indexed triangles, CCW,
two-sided foliage. Canonical projection matrices use depth0..1; GL/GLES vertex
sources convert Z. Vulkan reverses Y; WebGPU uses its own standard clip mapping.
Profiles and generated geometry are CPU-owned pure data. Current wind is CPU
deformation from a shared analytic field; perches can request identical time.

Native color shader sources are vegetation.gl.vert/.frag, vegetation.vert/.frag
(Vulkan), vegetation.ios.vert/.frag, vegetation.wgsl. The color shader needs
viewProjection, sunViewProjection, sunDirection, sunColor, ambientColor and a
shadow depth map. Vulkan/WGSL Scene UBO layout is two mat4 then four vec4 records:
sunDirection, sunColor, ambientColor, options (u32[4], first enables shadows).
Binding0=Scene, binding1=shadow depth. Vulkan uses sampled combined depth image;
WGSL uses texture_depth_2d with integer textureLoad PCF, no sampler binding.
GL/GLES use corresponding standalone uniforms and sampler2D shadowDepth.
Shadow color/receiver origins must be identical camera-relative metres. Bind
viewProjection=sunViewProjection in the GLSL depth pass and use the matching
vegetation.shadow*.frag silhouette; WGSL has vs_shadow/fs_shadow entry points.
Use a separate shadow target/pass. Existing depth testing alone is not sunlight
shadowing. The shader exposes shadowsEnabled=false only for explicit unshadowed
debugging, never as proof the full target is finished. Terrain receiving tree
shadows still needs shared native renderer support from the integration owner.

Replace old solid tree crowns in EnvironmentGeometry when the live material
path is wired. Do not draw both. Keep grass/clods and authoritative terrain and
soil collision separate. Set vegetation budget from measured remaining scene

The geometry samples existing tree sites and uses the emitted triangle count for level selection.
Only near branch meshes carry analytic wind; independent leaf flutter is frozen

QueryGeometry retains JSON diagnostics including forest cell/budget/cache counts.
Do not claim forested mountains or improved FPS verified from source alone.

QueryPerches input: {position,up,min_distance,max_distance,limit<=12,seed,time?}.
Output {revision,perches:[{site_id,branch_id,position,up,suitable:true}]}.
World positions, final perch annulus, >=7m candidate separation; empty result
means no habitat. No fake fallback. Uses state, not visible trees. Bird relocation
distance >=8m remains the bird caller's check. Soil support/flood/water clearing
must be provided through shared accepted world-state operations before claiming
those habitat effects. Existing suitability uses terrain descriptors only.

Snapshot/Restore are pure value operations. The application owner must wire
atomic session persistence and error handling; generating a snapshot is not
proof of saving to disk. AdvanceGrowth requires explicit ecological years <=1
per call, bounded region, advances stored individuals and materializes state;
no arbitrary fast-forward or background planet-wide ecology was selected.
ApplyDamage resolves the actual stable site near the supplied world position,
removes a branch subtree or whole tree, returns every detached structural branch
and explicitly reports physical_material_created=false. Only invoke after an
accepted physical transfer. Wood/root material creation, failure thresholds,
mass accounting and contact remain Rewrite ownership. These are not implemented
by deleting appearance. No calls originate in real-time audio callbacks.

Native typed adapter: vegetation::packet::Packet::from_geometry(value,Scene)
parses QueryGeometry output, bounds indices/vertices, retains f64 origin/u64
revision and exposes64-byte vertex_bytes()/u32 index_bytes(). Scene contains
column-major view_projection and sun_view_projection plus sun_direction,
sun_color, ambient_color vec4s and options:u32[4]. Scene.bytes() explicitly packs
192bytes; options[0] enables shadows. Caller supplies matrices and lighting in
the packet origin, and supplies actual shadow targets/passes. Existing shaders
remain unchanged. GL uniforms can use Scene fields directly.

Stable plant identity correction: site IDs now encode cube face and two signed
20-bit site coordinates in disjoint u64 fields (high bit marks this layout).
The former XOR-folded coordinate value remains only a placement noise seed,
so existing root jitter, habitat selection and architectural profile selection
are preserved. Opposite signed odd coordinate pairs no longer alias state.
Snapshot schema is now2. Legacy schema1 lacks coordinates and may have combined
two plants into one state key; Restore rejects it before mutation, with explicit
identity-migration error. No legacy files are overwritten or automatically
retargeted. A reliable legacy migration needs original root/coordinate evidence;
there is no universally correct mapping from the old ID alone. New age/damage
snapshots round-trip under schema2. Branch/perch wind time never changes roots.

Native iPhone GLES helper implemented behind unchanged Render/Vegetation/GLES.h
in NEW Render/Vegetation/GLES.m (Objective-C, matching current iOS build language).
shader_root is application asset root. All5header functions supplied. Parent
provides owning current EAGL GLES3 context for create/shadow/draw/destroy,
registers this translation unit in build, invokes passes before presentation,
and destroys helper before context teardown. No dispatch, drawable or present
is owned here. Wrong-context destruction is refused; caller must retry while
correct owning context is current, or resources cannot be released safely.

Indexed buffers enforce64bytevertices/u32indices and bounded finite input.

Framebuffer/requested viewport restored on every GL-mutating return path;
